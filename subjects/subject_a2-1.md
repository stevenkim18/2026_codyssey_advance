## 문제 기술

### 1. 미션 소개

선형대수, 미적분, 확률·통계는 AI 모델이 데이터를 처리하고 학습하는 과정의 수학적 기반이다. 신경망의 각 층에서 일어나는 연산은 행렬 곱셈이며, 가중치를 업데이트하는 과정은 경사하강법이라는 최적화 알고리즘을 따른다.

이 미션에서는 NumPy로 수학적 계산과 구현을 하고, Matplotlib/Seaborn으로 시각화한다. 행렬 변환의 기하학적 의미를 시각화하고, 고유값 분해를 직접 구현하며, 연쇄 법칙을 바탕으로 역전파 수식을 유도한다. 또한 경사하강법의 수렴 과정을 등고선 위에 시각화하고, 손실 함수와 확률 분포의 관계를 탐구한다.

이 경험은 이후 딥러닝 미션에서 AutoGrad 엔진을 구현할 때 수학적 기반이 되며, 모델의 동작 원리를 해석하고 문제를 진단하는 능력을 기르는 데 도움이 된다.

## 기능 요구 사항

다음 요구 사항을 모두 만족해야 한다.

### 1. 선형대수: 행렬 변환과 분해

- 단위 원에 회전 행렬 R(θ)을 적용하고, 변환 전후를 하나의 Figure에 겹쳐 출력한다.
- 단위 원에 스케일링 행렬 S(2, 0.5)를 적용하고, 타원 형태의 결과를 출력한다.
- 단위 원에 전단 행렬 Sh(k)를 적용하고, 기울어진 형태의 결과를 출력한다.
- 행렬식 det(A)을 계산하고 변환 후 도형의 면적 비율과 비교하여 오차가 1% 이내인지 확인한다.
- Power Iteration 알고리즘을 구현하여 최대 고유값을 계산한다.
- 직접 계산한 고유값과 np.linalg.eig 결과를 비교하여 오차가 5% 이내인지 확인한다.
- SVD로 이미지를 압축·복원하고, k=10, 50, 100일 때의 결과를 하나의 Figure에 비교 출력한다.

### 2. 미적분: Gradient 시각화

- f(x)=x²에서 x=3일 때 수치 미분을 계산한다. 해석적 미분 결과인 6과 비교하여 오차가 1e-4 이내인지 확인한다.
- 2변수 함수 f(x, y)=x²+y²의 등고선 그래프를 그린다.
- 등고선 위 여러 점에서 Gradient 방향을 화살표로 표시한다.
- Gradient 화살표가 등고선에 수직임을 시각적으로 확인한다.

### 3. 역전파: 연쇄 법칙 수식 유도

- 입력 2개 → 은닉 2개 → 출력 1개 구조의 2층 신경망 순전파 수식을 노트북에 작성한다.
- 출력층에서 입력층 방향으로 연쇄 법칙을 적용하여 역전파 수식을 단계별로 유도한다.
- 다음 숫자 예제로 순전파를 손으로 계산한다.
  - 입력: x = [1, 0]
  - 가중치 1: W1 = [[0.1, 0.2], [0.3, 0.4]]
  - 편향 1: b1 = [0, 0]
  - 가중치 2: W2 = [0.5, 0.6]
  - 편향 2: b2 = 0
  - 활성화 함수: Sigmoid
  - 손실 함수: Binary Cross-Entropy (BCE), L = -(y·log(ŷ) + (1-y)·log(1-ŷ))
  - 정답: 원문에서 y_true 값이 비어 있다. 8절의 결과 예시는 y_true = 1을 사용한다.
- 순전파 중간값 z1, a1, z2, y_pred를 각각 기록한다.
- 다음 기울기를 모두 유도한다: ∂L/∂y_pred, ∂L/∂z2, ∂L/∂W2, ∂L/∂a1, ∂L/∂z1, ∂L/∂W1.
- 각 단계에서 텐서의 shape을 반드시 표기한다. 예: W1은 (2,2), x는 (2,), z1은 (2,).
- 같은 계산을 NumPy 코드로 수행하고, 손계산 결과와 소수점 넷째 자리까지 일치하는지 확인한다.

### 4. 최적화: 경사하강법 시각화

- Vanilla GD를 구현하고 f(x, y)=x²+y²에 적용한다.
- lr=0.1로 100회 반복한 뒤 (x, y)가 원점 근처(반경 0.1 이내)에 도달하는지 확인한다.
- 수렴 경로를 등고선 위에 점선으로 표시한다.
- lr=0.5 이상에서 최적화 경로가 발산함을 그래프로 확인한다.
- Momentum(beta=0.9)을 구현하고 Vanilla GD와 수렴 경로를 비교한다.
- 두 옵티마이저의 수렴 경로를 하나의 Figure에 겹쳐 출력한다.
- 타원형 함수 f(x, y)=x²+10y²에서도 두 옵티마이저의 수렴 경로를 비교하여 Momentum의 이점을 확인한다.

### 5. 확률·통계: 손실 함수의 수학적 기반

- 정규분포 N(0,1)과 N(2,0.5)의 PDF 곡선을 하나의 Figure에 비교 출력한다.
- 베르누이 분포 B(0.3)과 B(0.7)의 PMF 막대그래프를 하나의 Figure에 비교 출력한다.
- 소프트맥스 함수를 구현하고, 출력 벡터 합과 1.0의 차이가 1e-6 이내인지 확인한다.
- “MSE 최소화 = 정규분포 가정하의 MLE”임을 수식으로 유도해 노트북에 작성한다.
- “Cross-Entropy 최소화 = 베르누이/카테고리 분포 가정하의 MLE”임을 수식으로 유도해 노트북에 작성한다.

### 역전파 손계산 예시

**2층 신경망: 입력(2) → 은닉(2) → 출력(1)**

순전파:

| 항목 | shape | 값 |
|---|---:|---|
| x | (2,) | [1, 0] |
| W1 | (2,2) | [[0.1, 0.2], [0.3, 0.4]] |
| z1 = W1 @ x | (2,) | [0.1, 0.3] |
| a1 = sigmoid(z1) | (2,) | [0.5250, 0.5744] |
| W2 | (2,) | [0.5, 0.6] |
| z2 = W2 @ a1 | scalar | 0.6071 |
| y_pred = sigmoid(z2) | scalar | 0.6473 |

역전파(y_true=1, BCE Loss):

| 항목 | shape | 값 |
|---|---:|---|
| ∂L/∂y_pred | scalar | -(1/0.6473) = -1.5449 |
| ∂L/∂z2 | scalar | y_pred - y_true = -0.3527 (체크포인트) |
| ∂L/∂W2 | (2,) | ∂L/∂z2 × a1 = [-0.1852, -0.2026] |
| ∂L/∂a1 | (2,) | ∂L/∂z2 × W2 = [-0.1764, -0.2116] |
| ∂L/∂z1 | (2,) | ∂L/∂a1 × σ'(z1) = [-0.0440, -0.0513] (체크포인트) |
| ∂L/∂W1 | (2,2) | outer(∂L/∂z1, x) = [[-0.0440, 0], [-0.0513, 0]] |

NumPy 검증: 손계산 결과와 소수점 넷째 자리까지 일치한다.

### MSE-MLE 연결 수식 예시

**MSE 최소화 = 정규분포 MLE**

가정: y = f(x) + ε, ε ~ N(0, σ²)

따라서:

p(y|x) = (1/√(2πσ²)) × exp(-(y - f(x))² / 2σ²)

최대우도추정(MLE):

- argmax Π p(yᵢ|xᵢ) = argmax Σ log p(yᵢ|xᵢ)
- = argmax Σ [-(yᵢ - f(xᵢ))² / 2σ² - log(√(2πσ²))]
- = argmin Σ (yᵢ - f(xᵢ))² (상수 제거)
- = argmin MSE

결론: 정규분포를 가정하면 MSE를 최소화하는 것은 MLE와 동일하다.

### 옵티마이저 비교 예시

|---|---|
| Vanilla GD | (0.08, 0.08), 원점 도달 |
| Momentum | (0.02, 0.02), 더 빠르게 수렴 |

**f(x, y)=x²+10y², 초기점 (5, 5), lr=0.05**

- Vanilla GD: 지그재그 경로로 느리게 수렴
