# 미션: CV, NLP 자율 주제 프로젝트

> 팀 필수 미션 · AI/SW 심화 · Term Project · 80시간

## 1. 미션 소개

AI/SW 심화 과정의 팀 종합 프로젝트다. CV 또는 NLP를 중심으로 문제 정의→데이터 구축→모델 개발→서비스 구현의 전 주기를 수행하고, 팀 협업 결과를 포트폴리오로 완성한다.

## 2. 최종 결과물

- 서비스 기획서: 문제, 사용자, 기술 접근, 일정
- 요구사항 정의서
- 서비스 아키텍처 다이어그램
- 안정적으로 동작하는 AI 서비스
- GitHub 저장소와 모든 소스·문서
- `README.md`: 개요, 실행, 기술 스택, 팀원 역할
- 모든 팀원의 의미 있는 커밋 기록
- 발표 자료

## 3. 주제 선택

### CV 예시

- 딥러닝 객체 탐지 시스템
- 포즈/동작 인식 시스템
- 이미지 분류와 XAI 시스템

### NLP 예시

- 임베딩 기반 콘텐츠 추천
- RAG 기반 문서 QA
- 사전학습 모델 기반 텍스트 분류

자율 주제는 CV 또는 NLP를 핵심으로 사용해야 하며 기획서에 선정 이유와 기술적 타당성을 적는다.

## 4. 기능 요구 사항

- 팀 3~5명, 5명 권장
- 역할을 명확히 나누고 모든 팀원이 실질적으로 기여
- 기획서에 배경, 문제, 사용자, 시나리오, 요구사항, 아키텍처, 기술 스택, 역할, 일정 포함
- 주제에 맞는 데이터 수집·전처리
- CV/NLP 핵심 모델 또는 알고리즘 구현
- 모델을 CLI, GUI, 웹 등 서비스 인터페이스와 연동
- 일관된 코드 컨벤션과 체계적인 Git 버전 관리

## 5. 과제 목표

- AI가 해결하는 문제와 기술 접근 설명
- CV/NLP 서비스 파이프라인 설계·구현 경험 설명
- 본인의 역할, 기여, 협업 과정 설명
- 기술적 문제와 해결 과정 설명

## 6. 보너스 과제

- 외부 접근 가능한 서비스 배포
- 실사용자 테스트와 피드백 반영
- 기술 문제와 인사이트를 다룬 블로그 작성

## 7. 개발 환경과 제약

- Python 3.10 이상
- 언어·프레임워크·라이브러리는 자유이나 선정 이유를 문서화
- CV 또는 NLP가 서비스 핵심이어야 함
- 팀 협업과 GitHub 기록 필수
- 서비스 기획서, 프로그램, 발표 자료 모두 제출
- 외부 완성 코드 복사 및 특정 인원의 단독 개발 금지
