# CV, NLP 자율 주제 프로젝트

분야: AI/SW 심화  
구분: Term Project  
학습시간: 80시간  
필수/선택: 필수

## 문제기술

### 기술적 설명

### 1. 미션 소개

Term Project는 AI/SW 심화 과정의 마무리를 장식하는 팀 단위 종합 프로젝트입니다. 지금까지 학습한 Computer Vision, Natural Language Processing, Machine Learning, Deep Learning의 핵심 기술들을 융합하여 실제 사용 가능한 AI 서비스를 기획하고 구현합니다.

본 미션에서는 CV 또는 NLP 기반의 예시 주제를 선택하거나, 자율 주제로 팀만의 독창적인 서비스를 개발합니다.

단순히 모델을 학습시키는 것을 넘어, "문제 정의 → 데이터 구축 → 모델 개발 → 서비스 구현"으로 이어지는 프로젝트 전 주기를 경험합니다.

또한, 팀원 간 역할 분담과 협업을 통해 실무에서 요구되는 프로젝트 수행 역량을 기릅니다.

이 프로젝트는 AI/SW 심화 과정에서 습득한 기술 역량을 증명하는 포트폴리오가 될 것입니다.

### 2. 최종 결과물

CV 또는 NLP 기반의 AI 서비스를 팀 단위로 완성한다.

1. 서비스 기획서
   - 문제 정의, 타겟 사용자, 기술적 접근 방식, 일정 계획 포함
   - 요구사항 정의서
   - 서비스 아키텍처 다이어그램

2. AI 서비스 프로그램
   - 선택한 주제의 문제를 해결하는 AI 기반 서비스
   - 모든 기능이 에러 없이 실행되고 안정적으로 동작

3. GitHub 저장소
   - README.md (프로젝트 개요, 실행 방법, 팀원 역할 등)
   - 모든 소스 코드와 문서
   - 모든 팀원의 의미 있는 커밋 기록

### 3. 과제 목표

이 과제를 마친 후, 학습자는 아래를 스스로 설명할 수 있어야 한다.

- 선택한 주제에서 AI가 해결하는 문제와 기술적 접근 방식을 설명할 수 있다.
- CV 또는 NLP 기술을 활용한 서비스 파이프라인을 설계하고 구현한 경험을 설명할 수 있다.
- 팀 프로젝트에서 본인의 역할과 기여, 협업 과정을 설명할 수 있다.
- 프로젝트 진행 중 발생한 기술적 문제와 해결 과정을 설명할 수 있다.

### 4. 기능 요구 사항

다음 요구사항을 모두 만족해야 한다.

1. 주제 선택:
   - 아래 예시 주제 중 하나를 선택하거나, 자율 주제로 진행한다.

   1. CV (Computer Vision) 예시 주제

      | 주제 | 설명 |
      | --- | --- |
      | 딥러닝 기반 객체 탐지 시스템 | 이미지 또는 영상에서 객체를 탐지하고 분류하는 시스템 |
      | 포즈/동작 인식 시스템 | 사람의 신체 키포인트를 추정하여 동작이나 제스처를 인식하는 시스템 |
      | 이미지 분류 및 해석(XAI) 시스템 | 이미지를 분류하고 모델의 판단 근거를 시각화하는 시스템 |

   2. NLP (Natural Language Processing) 예시 주제

      | 주제 | 설명 |
      | --- | --- |
      | 임베딩 기반 콘텐츠 추천 시스템 | 텍스트 임베딩을 활용하여 의미적으로 유사한 문서나 상품을 추천하는 시스템 |
      | RAG 기반 문서 QA 시스템 | 검색 증강 생성(RAG)을 활용하여 문서 기반 질의응답을 수행하는 시스템 |
      | 텍스트 분류 시스템 | 사전학습 모델을 활용하여 텍스트를 카테고리별로 분류하는 시스템 |

   3. 자율 주제
      - CV 또는 NLP 기술을 핵심으로 활용하는 주제라면 자유롭게 선정 가능
      - 자율 주제 선정 시, 기획서에 주제 선정 이유와 기술적 타당성을 명시

2. 팀 구성
   - 팀 인원: 3~5인 (5명 권장)
   - 팀원 간 역할을 명확히 분담한다.
   - 모든 팀원이 프로젝트에 실질적으로 기여해야 한다.

3. 서비스 기획서 작성
   - 프로젝트 개요 및 배경
   - 해결하고자 하는 문제 정의
   - 타겟 사용자 및 사용 시나리오
   - 요구사항 정의서
   - 서비스 아키텍처 다이어그램
   - 기술 스택 및 선정 이유
   - 팀원 역할 분담
   - 일정 계획

4. AI 서비스 개발
   - 선택한 주제에 적합한 데이터를 수집하고 전처리한다.
   - CV 또는 NLP 핵심 기술을 활용하여 모델/알고리즘을 구현한다.
   - 구현한 모델을 서비스 형태로 연동한다.
     - CLI, GUI, 웹 등 인터페이스 형태는 자유롭게 선택

5. 프로젝트 문서화
   - README.md에 프로젝트 개요, 팀원 역할, 기술 스택, 실행 방법을 정리한다.
   - 코드는 일관된 컨벤션을 따라 작성한다.
   - Git을 활용하여 체계적으로 버전 관리를 한다.
   - 모든 팀원이 의미 있는 커밋 기록을 남긴다.

### 5. 보너스 과제

1. 서비스 배포
   - 외부에서 접근 가능한 형태로 서비스를 배포한다.

   - 프로젝트 과정에서 해결한 기술적 문제와 인사이트를 블로그 포스트로 작성한다.

  ```css

  축구 경기 영상에서 선수와 공을 실시간으로 추적하여 
  이동 경로와 점유율을 분석하는 시스템입니다.
  
  ## 팀원 및 역할
  | 이름 | 역할 | 담당 업무 |
  |------|------|-----------|
  | 홍길동 | PM / CV | 프로젝트 관리, 객체 추적 알고리즘 개발 |
  | 김철수 | CV | 배경 차분 및 객체 감지 구현 |
  | 이영희 | Frontend | 분석 결과 시각화 대시보드 개발 |
  | 박민수 | Data | 영상 데이터 전처리 및 라벨링 |
  
  ## 기술 스택
  - CV: Python, OpenCV, NumPy
  - ML: Scikit-learn
  - Frontend: Streamlit
  
  ## 실행 방법
  pip install -r requirements.txt
  python main.py --video sample.mp4
  
  ## 주요 기능
  1. 실시간 선수/공 객체 감지 및 추적
  2. 이동 경로 시각화
  3. 팀별 점유율 분석
  4. 히트맵 생성
  ```
