# 미션: 글 속에 숨은 정보와 기분(좋음/나쁨)을 자동으로 뽑아내기

> 개인 필수 미션 · AI/SW 심화 · 자연어 처리 · 70시간

## 1. 미션 소개

정규표현식과 감성 사전을 사용해 비정형 텍스트에서 구조화된 정보와 감성을 추출한다. 규칙 기반 접근의 높은 정밀도·해석 가능성과 낮은 확장성·유지보수 한계를 평가한다.

## 2. 최종 결과물

- 이메일·전화번호·날짜·금액·URL 정규표현식 추출 모듈
- 감성 점수, 부정어, 강조어 처리 시스템
- 정보 추출과 감성 분석 성능 및 실패 사례를 담은 `README.md`
- 설치·실행 방법

## 3. 기능 요구 사항

### 정보 추출

- 5가지 패턴별 최소 3개 변형 처리
- 날짜 ISO 8601, 금액 정수, 전화번호 하이픈 등 정규화 형식 반환
- 패턴별 테스트 문장 10개 이상, 전체 50개 이상
- Precision·Recall 계산 및 실패 사례 5건 이상 유형화

### 감성 분석

- 공개 사전 또는 직접 구축한 200개 이상 감성 단어
- 토큰화, 감성 점수 합산, 부정어 반전, 강조어 가중치
- 이중부정 단일 패턴 처리
- 레이블 데이터 100개 이상으로 Accuracy·F1 측정
- 부정/강조 규칙 적용 전후 비교 및 오분류 10건 이상 분석
- 반어, 복합 감성, 문맥 의존 표현은 선택 범위

## 4. 보너스 과제

- 주민등록번호·카드번호·주소 마스킹
- 규칙 기반과 TF-IDF 기반 감성 분류 성능 비교
- 음식/가격 등 Aspect-based 감성 분석

## 5. 데이터 가이드

- 정보 추출 문장은 다양한 형식으로 직접 생성
- 감성 데이터: NSMC 등
- 감성 사전: KNU 한국어 감성사전 또는 직접 구축
- 외부 사전 사용 시 도메인 단어 30개 이상 직접 추가

## 6. 개발 환경과 제약

- Python 3.10+
- Python 내장 `re`, KoNLPy 또는 NLTK 사용 가능
- 모든 정규표현식에 의도와 매칭 범위 주석 작성
- 외부 감성 사전 출처 명시
- `requirements.txt` 또는 `environment.yml` 필수
