## 문제기술

### 기술적 설명

### 1. 미션 소개

앞선 미션(NLP Mission 1)에서 TF-IDF와 코사인 유사도를 활용하여 문서를 검색하고 분류하는 통계 기반 접근법을 경험했다. 통계 기반 방법은 대규모 데이터에서 일반적인 패턴을 포착하는 데 강하지만, 특정 형식의 정보를 정확히 추출하거나 도메인 규칙을 명시적으로 반영하는 데에는 한계가 있었다. 예를 들어 "이메일 주소를 추출하라"는 요구에 TF-IDF는 적합하지 않다.

정보 추출(Information Extraction)은 비정형 텍스트에서 구조화된 정보를 뽑아내는 기술이다. 이력서에서 연락처를 추출하거나, 계약서에서 날짜와 금액을 파악하거나, 리뷰에서 감성을 판단하는 작업이 이에 해당한다.

이 미션에서는 규칙 기반(Rule-based) 접근법의 두 가지 핵심 도구를 활용한다:

- 정규표현식(Regular Expression): 텍스트에서 특정 패턴을 추출하는 도구
- 감성 사전(Sentiment Lexicon): 텍스트의 감성을 판단하는 도구

이 과정을 통해 규칙 기반 접근법의 장점(높은 정밀도, 해석 가능성)과 한계(낮은 확장성, 유지보수 어려움)를 직접 체감한다.

핵심 질문: "규칙으로 언어를 정의할 수 있는가?"

실무 시나리오: 고객 문의 텍스트에서 연락처/날짜/금액 등 핵심 정보를 추출한 후, 해당 문의의 감성(불만/만족)을 판단하는 통합 파이프라인을 구축한다고 상상해 보자. 이것이 규칙 기반 NLP의 전형적인 활용 시나리오이다.

### 4. 기능 요구 사항

다음 요구사항을 모두 만족해야 한다.

1. 정규표현식 기반 정보 추출
   - 다음 5가지 패턴을 추출하는 함수를 구현한다:
     - 이메일 주소 (예: user@domain.com, user.name@sub.domain.co.kr)
     - 전화번호 (예: 010-1234-5678, 02-123-4567, 031-1234-5678)
     - 날짜 (예: 2024년 1월 15일, 2024/01/15, 2024-01-15)
     - 금액 (예: 10,000원, 1억 2천만원, $100)
     - URL (예: https://www.example.com/path?query=value)

   - 각 패턴에 대해 최소 3가지 이상의 변형을 처리한다.
   - 추출 결과를 정규화된 형식으로 반환한다. . (예: 날짜는 ISO 8601 형식, 금액은 정수값, 전화번호는 하이픈 구분 통일 형식 등)

2. 감성 사전 및 감성 분석
   - 공개 감성 사전을 활용하거나 직접 구축한다. (최소 200개 이상 단어)
   - 문장의 감성 점수를 계산하는 함수를 구현한다.
   - 부정어 처리를 구현한다. (예: "좋지 않다" → 부정)
   - 강조어 처리를 구현한다. (예: "매우 좋다" → 강한 긍정)
   - 감성 분석 범위 구분

     최소 요구 (필수): 토큰화 + 감성사전 점수 합산 + 부정어 반전 + 강조어 가중치 + 이중부정 단일 패턴 처리

     도전 범위 (선택): 반어/비꼔, 복합 감성(Aspect), 문맥 의존 표현 등은 보너스 과제로 분류

3. 시스템 평가
   - 정보 추출 평가
     - 직접 작성한 테스트 문장 50개 이상(패턴별 10문장 이상)으로 구성하고, 패턴별 정밀도(Precision)와 재현율(Recall)을 계산한다.
     - 실패 사례 5건 이상을 유형별로 분류하고 원인을 분석한다.

   - 감성 분석 평가
     - 레이블 데이터 100개 이상으로 정확도(Accuracy) 및 F1 점수를 산출한다.
     - 부정어/강조어 규칙 적용 전후 성능을 비교한다.
     - 오분류 사례 10건 이상을 수집하고 원인을 분석한다

### 8. 결과 예시

- 정보 추출 결과 :

  ```css
  === 정보 추출 결과 ===
  입력: "문의: support@company.co.kr, 전화 02-1234-5678
         일시: 2024년 3월 15일, 참가비: 50,000원"
  
  추출 결과:
  - 이메일: support@company.co.kr
  - 전화:   02-1234-5678
  - 날짜:   2024-03-15 (정규화)
  - 금액:   50000 (정규화)
  ```

- 감성 분석 과정 :

  ```css
  === 감성 분석 과정 ===
  문장: "이 식당은 정말 맛있지 않았어요"
  
  1. 토큰화: [이, 식당, 은, 정말, 맛있, 지, 않았어요]
  2. 감성 단어 탐지: 맛있(+2)
  3. 부정어 탐지: '않았어요' → 감성 반전
  4. 강조어 탐지: '정말' → 강도 ×1.5
  
  계산: (+2) × (-1) × 1.5 = -3
  최종 판정: 부정
  ```

- 규칙 실패 사례 분석 :

  ```css
  === 실패 사례 분석 ===
  ```
