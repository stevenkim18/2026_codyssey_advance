## 1. 비유: 여러 신호를 모아서 결정하는 스위치

아이스크림 추천 로봇에 `날씨(더움)`와 `가격(쌈)` 두 신호를 넣어 보자. 신호마다 중요도가 다르다. 이를 가중치로 표현하여 **가중합**을 계산한다.

\[z=w_1x_1+w_2x_2+b\]

`x`는 입력, `w`는 중요도(가중치), `b`는 판단 기준을 움직이는 편향이다. 단순 퍼셉트론은 `z`가 0 이상이면 1, 아니면 0을 출력한다.

## 2. 입력 → 계산 → 출력

예를 들어 `x=[1,0]`, `w=[2,-1]`, `b=-0.5`이면 `z=1.5`로 출력은 1이다. `x=[0,1]`이면 `z=-1.5`로 출력은 0이다.

```python
import numpy as np

def perceptron(x, w, b):
    z = np.dot(x, w) + b
    return int(z >= 0)

w = np.array([2., -1.])
for x in [np.array([1.,0.]), np.array([0.,1.])]:
    print('input=', x, 'output=', perceptron(x,w,-.5))
```

## 3. 왜 층을 여러 개 쓰나?

한 개의 직선 결정 경계로는 XOR처럼 복잡한 분류를 정확히 해결할 수 없다. 중간층(은닉층)을 둔 신경망은 **비선형 활성화**를 통해 더 복잡한 패턴을 배울 수 있다. 학습 가능한 신경망은 가중치를 손실이 작은 방향으로 업데이트한다.

\[\text{입력} \longrightarrow \text{은닉층} \longrightarrow \text{출력층}\]

실습에서 쓸 **2→2→1 구조**는 입력 숫자 2개, 은닉 뉴런 2개, 출력 1개를 뜻한다. 은닉층의 출력과 마지막 출력층도 계산되므로 전체적으로 **두 번의 가중치 연산**이 일어난다.

## 4. 자주 헷갈리는 점

- 뉴런은 생물학적 뇌 세포 그 자체가 아니라 **수학적 계산 단위**다.
- `z`는 아직 활성화 함수를 거치기 전 값이다.
- 계단 함수는 직관적이지만 미분이 어려워, 실제 학습에는 Sigmoid나 ReLU를 흔히 쓴다.
