## 1. 가중치는 연결 강도, 편향은 기준점

입력 2개가 뉴런 2개로 연결되면 연결선이 `2×2=4`개 필요하다. 연결마다 값이 하나씩 있으므로 가중치는 `2×2` 행렬로 저장한다.

\[Z=XW+b\]

**shape(모양) 추적**은 신경망 디버깅의 첫 번째 기술이다.

| 값 | 단일 샘플 2차원 배열 | 뜻 |
|---|---|---|
| `X` | `(1,2)` | 입력 2개 |
| `W` | `(2,2)` | 입력 2개→뉴런 2개 |
| `b` | `(2,)` | 출력 뉴런별 편향 |
| `Z` | `(1,2)` | 뉴런 출력 전 단계 |

## 2. 행렬 계산 실습

```python
import numpy as np

X = np.array([[1., .5]])
W = np.array([[.2, -.3], [.4, .1]])
b = np.array([.1, -.2])
Z = X @ W + b
print('X:', X.shape, 'W:',W.shape, 'b:',b.shape, 'Z:',Z.shape)
print('Z:', Z)  # [[0.5, -0.45]]
assert Z.shape == (1,2)
assert np.allclose(Z, [[.5, -.45]])
```

**손계산** 첫 번째 뉴런: `1×0.2 + 0.5×0.4 + 0.1 = 0.5`. 두 번째 뉴런: `1×(-0.3) + 0.5×0.1 - 0.2 = -0.45`.

## 3. 여러 입력을 한꺼번에 처리한다면?

```python
batch = np.array([[1., .5], [0.,1.], [1.,1.]])  # (3,2)
print((batch @ W + b).shape)  # (3,2)
```

`b`의 `(2,)`는 NumPy의 브로드캐스팅으로 배치의 모든 행에 더해진다. 학습 시 각 샘플에서 구한 `dW`, `db`를 합하거나 평균 내어 한 번에 업데이트할 수 있다.

## 4. 실수 방지

`X * W`는 원소별 곱셈, `X @ W`는 행렬 곱셈이다. `W`의 차원을 `(은닉 뉴런 수, 입력 수)`로 저장하는 프레임워크도 있으므로 **현재 수식의 축 약속**을 꼭 확인하자.
