## 1. IQR이란?

**IQR(Interquartile Range, 사분위 범위)**은 데이터가 얼마나 퍼져 있는지 확인하고, **이상치(Outlier)를 탐지할 때 사용하는 통계적 방법**이야.

쉽게 말하면, 전체 데이터를 작은 값부터 큰 값까지 정렬했을 때 **가운데 50%의 데이터가 얼마나 넓게 퍼져 있는지** 나타내는 값이야.

### 먼저 사분위수(Quartile)를 이해하자

데이터를 오름차순으로 정렬하고 4등분하면 다음과 같은 기준이 생겨.

| 구분 | 의미 |
|---|---|
| Q1 (제1사분위수) | 하위 25% 지점의 값 |
| Q2 (제2사분위수) | 하위 50% 지점의 값 = 중앙값 |
| Q3 (제3사분위수) | 하위 75% 지점의 값 |

IQR은 Q3에서 Q1을 뺀 값이야.

\[
\boxed{IQR = Q3 - Q1}
\]

예를 들어 쇼핑몰에서 고객 5명의 구매 금액이 다음과 같다고 해보자.

```text
10,000원
20,000원
30,000원
40,000원
50,000원
```

Pandas의 기본 분위수 계산 방식으로 구하면 다음과 같아.

- Q1 = 20,000원
- Q2 = 30,000원
- Q3 = 40,000원

따라서 IQR은 다음과 같아.

\[
IQR = 40,000 - 20,000 = 20,000원
\]

즉, 가운데 50% 데이터의 범위가 20,000원이라는 뜻이지.

## 2. IQR로 이상치를 찾는 방법

일반적으로 다음 기준을 사용해.

**이상치 판단 기준**

\[
하한 = Q1 - 1.5 \times IQR
\]

\[
상한 = Q3 + 1.5 \times IQR
\]

하한보다 작거나 상한보다 큰 값을 이상치로 판단하는 거야.

앞의 예제를 적용하면 다음과 같아.

```text
Q1 = 20,000
Q3 = 40,000
IQR = 20,000

하한 = 20,000 - (1.5 × 20,000)
     = -10,000원

상한 = 40,000 + (1.5 × 20,000)
     = 70,000원
```

따라서 구매 금액이 **70,000원을 초과하면 이상치 후보**로 분류돼.

예를 들어 구매 금액이 100,000원인 고객이 있다면 이상치가 될 수 있겠지.

단, 이 고객이 VIP라서 많이 구매한 것일 수도 있어. 따라서 **이상치라고 해서 무조건 잘못된 데이터는 아니야.**

## 3. Python으로 구현하기

이번 과제에서는 Pandas로 간단하게 구현할 수 있어.

```python
import pandas as pd

df = pd.DataFrame({
    "price": [10000, 20000, 30000, 40000, 50000, 100000]
})

# 1. 사분위수 계산
q1 = df["price"].quantile(0.25)
q3 = df["price"].quantile(0.75)

# 2. IQR 계산
iqr = q3 - q1

# 3. 이상치 경계 계산
lower = q1 - 1.5 * iqr
upper = q3 + 1.5 * iqr

# 4. 이상치 탐지
outliers = df[
    (df["price"] < lower) |
    (df["price"] > upper)
]

print(outliers)
```

여기서 주목할 부분은 다음 코드야.

```python
(df["price"] < lower) | (df["price"] > upper)
```

Pandas의 벡터화된 연산으로 모든 행에 조건을 적용하기 때문에 Python의 `for` 반복문을 직접 작성하지 않아도 돼.

참고로 앞서 설명한 5개 데이터와 달리, 이 코드에는 100,000원까지 포함된 6개 값이 있어. 따라서 사분위수와 이상치 경계가 다시 계산돼. 이 6개 값에서 100,000원은 IQR 기준 이상치로 탐지돼.

## 4. IQR의 장점과 한계

이번 과제의 평가 항목 3에서 특히 중요하게 보는 부분이야.

| 장점 | 한계 |
|---|---|
| 극단적인 값의 영향을 비교적 적게 받음 | 비대칭 분포에서 정상적인 큰 값도 이상치로 판단할 수 있음 |
| 데이터가 정규분포를 따르지 않아도 사용 가능 | 데이터가 적으면 사분위수가 불안정할 수 있음 |
| 계산이 간단하고 직관적 | 여러 변수 사이의 관계를 고려하지 못함 |
| 이상치 후보를 빠르게 식별 가능 | 이상치가 실제 오류인지 판단하지 못함 |

### 쇼핑몰 데이터에서는 어떻게 활용할까?

예를 들어 상품 가격을 분석한다고 해보자.

대부분 상품이 1만~10만 원인데, 일부 상품이 300만 원이라면 IQR은 300만 원짜리 상품을 이상치로 탐지할 가능성이 있어.

하지만 그 상품이 실제로 판매되는 고급 노트북이라면 제거하면 안 되겠지?

따라서 이번 과제에서는 다음과 같이 접근하는 것이 좋아.

**① IQR로 이상치를 탐지한다. → ② 이상치의 특성을 분석한다. → ③ 제거·보정·유지 중 적절한 처리 방법을 선택한다.**

그리고 처리 전후의 분포를 박스플롯(Box Plot)으로 시각화하면 평가 요구사항도 충족할 수 있어.

### 핵심 정리

**IQR은 데이터의 가운데 50% 범위를 이용해 극단적으로 크거나 작은 값을 탐지하는 방법이야.**

기억해야 할 공식은 세 가지야.

\[
IQR = Q3-Q1
\]

\[
하한 = Q1-1.5 \times IQR
\]

\[
상한 = Q3+1.5 \times IQR
\]

마지막으로 한 가지 중요한 개념이 있어.

**이상치 탐지(Detection)와 이상치 제거(Removal)는 서로 다른 작업이야.**

실제 데이터 분석에서는 이상치를 찾는 것보다, **왜 그 값이 이상치로 나타났고 어떻게 처리해야 하는지 판단하는 능력**이 더 중요해.
