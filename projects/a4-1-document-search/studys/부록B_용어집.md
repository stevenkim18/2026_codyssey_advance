| 정규화 (normalization) | 벡터를 자기 노름으로 나눠 길이를 1로 만드는 것. 방향은 그대로 | [3장](03_수학_기초.ipynb) |

| 코사인 유사도 (cosine similarity) | 내적 ÷ 두 노름의 곱. 두 벡터 사이 각도의 코사인. TF-IDF에서는 0~1 | [3장](03_수학_기초.ipynb) |

| 직교 (orthogonal) | 내적이 0인 관계. 문서끼리는 겹치는 단어가 없다는 뜻 | [3장](03_수학_기초.ipynb) |
| 행렬 (matrix) | 숫자를 직사각형으로 배열한 표. 크기는 (행 수, 열 수) | [3장](03_수학_기초.ipynb) |
| 행렬 × 벡터 | 행렬의 각 행과 벡터를 내적한 결과를 모은 것. `(m, n) × (n,) → (m,)` | [3장](03_수학_기초.ipynb) |
| 엔트로피 (entropy) | 분포가 얼마나 고르게 퍼졌는지 나타내는 값. 정규화하면 0~1 | [10장](10_불용어와_전처리_파이프라인.ipynb) |

| 문맥 임베딩 (contextual embedding) | 문장 속 문맥에 따라 같은 단어도 다른 벡터가 되는 방법 (BERT) | [21장](21_BoW의_한계.ipynb) |
| 서브워드 (subword) | 단어를 더 작은 조각으로 나누는 토큰화 (BPE, WordPiece). OOV를 줄인다 | [21장](21_BoW의_한계.ipynb) |
